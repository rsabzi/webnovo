## ۱) خلاصهٔ یک‌پاراگرافی

بخش نمونه‌کارها کامل بازنویسی شد: پنج پروژهٔ قبلی (که از مونوریپوی خصوصی `bot-company` آمده بودند) حذف شدند و به‌جایشان **هفت پروژهٔ واقعی** از مخازن عمومی `github.com/rsabzi` نشست — هر کدام با مسئله، تصمیم فنی، خروجی کار و **لینک دموی زنده یا مخزن کد**. صفحهٔ «مطالعات موردی» هم که چهار کیس با نام مشتری و نقل‌قول ساختگی داشت، به همین پروژه‌های قابل راستی‌آزمایی تبدیل شد. سایت با `tsc --noEmit` و `next build` بدون خطا ساخته می‌شود.

## ۴) چرا این نسخه مشتری را جذب می‌کند

1. **قابل راستی‌آزمایی است، نه ادعا.** برای هر کارت، یا دموی زنده باز می‌شود یا مخزن کد. دکمهٔ دمو/کد به هدر صفحهٔ پروژه، کارت صفحهٔ اصلی، صفحهٔ نمونه‌کارها و مطالعات موردی اضافه شد.
2. **بدون نقل‌قول و نام مشتری ساختگی.** جای «نقل‌قول رضایت» ساختگی را بلوک «خودتان بررسی کنید — دموی زنده و کد پروژه» گرفت؛ همین برای خریدار فنی و غیرفنی قابل‌اعتمادتر است.
3. **هر پروژه یک مسئلهٔ واقعی کسب‌وکار را حل می‌کند.** متن‌ها با ساختار «چالش کارفرما ← راهکار و معماری ← خروجی کار» نوشته شدند و از اعداد و درصدهای اثبات‌نشدنی پرهیز شد.
4. **پوشش نیازهای مختلف مشتری.** سایت و فروشگاه، پنل مدیریت، ربات پیام‌رسان، سامانهٔ نوبت‌دهی چندکاناله، هوش مصنوعی، اپ دسکتاپ و افزونهٔ وردپرس — هر نوع مشتری خودش را در فهرست پیدا می‌کند.
5. **تصاویر واقعی.** کاورها و گالری‌ها از خود پروژه‌ها آمده‌اند (عکس محصولات کارگاه، بنر و محصولات فروشگاه، اسکرین‌شات واقعی داشبورد «همراه»).
6. **یکدستی داده.** صفحهٔ اصلی، نمونه‌کارها، مطالعات موردی، صفحات خدمات و sitemap همه از یک منبع (`src/data/projects.ts`) می‌خوانند؛ دیگر متن صفحهٔ اصلی با فهرست پروژه‌ها ناهم‌خوان نمی‌شود.

## ۶) نحوهٔ اعمال روی ریپوی `webnovosite`

```bash
# ۱) یک کلون تازه از ریپو
git clone https://github.com/rsabzi/webnovosite.git
cd webnovosite

# ۲) اجرای اسکریپت (patch + تصاویر + نصب + بیلد)
/path/to/webnovosite-portfolio/apply.sh "$PWD"

# ۳) بازبینی و انتشار
git add -A
git commit -m "portfolio: real GitHub projects, remove bot-company items"
git push
```

اسکریپت روی یک کلون تازه از `main` تست شده و `code.patch` بدون تعارض اعمال می‌شود. اگر ترجیح می‌دهید دستی کپی کنید، نسخهٔ نهایی همهٔ فایل‌های تغییریافته در پوشهٔ `files/` است (نام فایل‌های مسیردار با `-` تخت شده‌اند؛ مثلاً `files/src/app/projects-slug-page.tsx` همان `src/app/projects/[slug]/page.tsx` است).

### فایل‌های تغییریافته

```
src/data/projects.ts                        بازنویسی کامل (۷ پروژه، دسته‌بندی‌های جدید، liveUrl/repoUrl)
src/data/projects.en.ts                     بازنویسی کامل نسخهٔ انگلیسی
src/data/services.ts                        حذف ارجاع به پروژه‌های حذف‌شده + نرم‌کردن یک ادعا در FAQ
src/components/CaseStudiesContent.tsx       مطالعات موردی از دادهٔ واقعی + بلوک راستی‌آزمایی
src/components/EnCaseStudiesContent.tsx     نسخهٔ انگلیسی
src/app/page.tsx                            کارت‌های صفحهٔ اصلی از دادهٔ واقعی + متن بخش نمونه‌کارها
src/app/en/page.tsx                         نسخهٔ انگلیسی
src/app/projects/page.tsx                   متادیتا، متن معرفی و دکمه‌های دمو/کد پروژهٔ شاخص
src/app/en/projects/page.tsx                نسخهٔ انگلیسی
src/app/projects/[slug]/page.tsx            لینک‌شدن مخزن/دمو، عنوان گالری، ابعاد تصویر گالری
src/app/en/projects/[slug]/page.tsx         افزودن بلوک «See it for yourself» (دمو + کد)
src/lib/site-analytics.ts                   عنوان صفحات پروژه‌های جدید
public/images/works/{choob,abrsorati,hamrah,ai-file-organizer,member-bot,wordpress}/  ۲۹ فایل webp (۱.۸MB)
```

## ۸) کارهایی که پیشنهاد می‌کنم بعد از این انجام شود

1. **تأیید دامنهٔ `abrsorati.ir`.** لینک سایت فروشگاه از README مخزن برداشته شده؛ قبل از انتشار یک‌بار بازش کنید (من به اینترنت بیرون از گیت‌هاب دسترسی ندارم و نتوانستم زنده بودنش را چک کنم).
2. **صفحهٔ خدمت «طراحی سایت و فروشگاه» وجود ندارد.** چهار نمونه‌کار از هفت مورد، وب‌سایت/فروشگاه است اما صفحات خدمات فقط ربات و اتوماسیون را پوشش می‌دهد. یکی از این دو کار را بکنید: یک سرویس `web` بسازید، یا لینک‌های `serviceLinks` پروژه‌های وب را به همان صفحات موجود محدود نگه دارید (الان همین‌طور است).
3. **بازبینی باقی متن‌های بازاریابی.** صفحهٔ `/services` و کارت‌های «مطالعات موردی» صفحهٔ خدمات، هنوز چند روایت با ارقام کلی («رشد محسوس فروش ماهانه») دارد که از دورهٔ قبل مانده است. اگر می‌خواهید سایت صددرصد باثبات باشد، این‌ها هم باید مثل همین صفحه‌ها به شواهد قابل بررسی تبدیل شوند.
4. **تصویر واقعی برای سه پروژهٔ شماتیک** (سازمان‌ده فایل، ربات اعضا، افزونه‌ها) — بهترین حالت: یک اسکرین‌شات از پنل چت‌بات وردپرس و از داشبورد Electron.
5. **حذف نهایی فایل‌های بی‌استفاده** اگر دیگر به نوو برنمی‌گردید: `src/data/novo-music-player.json` و `public/images/works/novo/` و همچنین `case-ocr.jpg` و `case-marketplace.jpg`.

## ۹) محدودیت این سشن (مهم)

این سشن روی برنچ `arena/cc05045c-webnovo` از ریپوی **`rsabzi/webnovo`** باز شده است (که خودش یک مجموعهٔ پلاگین وردپرس است)، نه روی `rsabzi/webnovosite`. طبق قواعد سشن، من فقط در همین برنچ اجازهٔ commit/push دارم؛ بنابراین تغییرات سایت به‌صورت **patch آمادهٔ اعمال + فایل‌های نهایی + تصاویر** در همین پوشه تحویل داده شده‌اند.

برای اینکه تغییرات مستقیم روی خود ریپو انجام و دیپلوی شود، سشن را روی ریپوی `rsabzi/webnovosite` باز کنید و همین پوشه را به آن منتقل کنید؛ بعد `apply.sh` را اجرا و پرزنت (PR) را باز کنید.
